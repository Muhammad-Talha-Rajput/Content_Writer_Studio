# Content Studio frontend

React, Vite and Tailwind application for Grands Digital Content Studio. See the [root README](../README.md) for setup and API/worker requirements.

Use `npm ci`, then `npm run dev`. Verify with `node --test src/lib/generationProgress.test.js`, `npm run lint` and `npm run build`. Provider credentials are managed by the backend; frontend environment variables must contain only public configuration.
